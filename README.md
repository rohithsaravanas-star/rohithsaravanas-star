## 📌 Featured Projects

### 🤖 **ForgeMind X** — Autonomous AI Manufacturing Platform
*Intelligent engineering automation using multi-agent AI*

**Repository:** [ForgeMind-X](https://github.com/rohithsaravanas-star/ForgeMind-X)

6-agent autonomous pipeline orchestrated with **NVIDIA NIM (Llama 3.1 70B)** for end-to-end engineering:
- **Requirements Agent** → Design Agent → Simulation Agent → Manufacturing Agent → Cost Agent → Report Agent
- Real-time 3D parametric model viewer with Three.js
- Interactive FEA stress analysis and Bill of Materials generation
- One-click executive PDF report generation
- Seamless zero-setup fallbacks for MongoDB and AI inference

**Tech:** Next.js, React 18, TypeScript, FastAPI, Python, MongoDB, Three.js, ReportLab, NVIDIA NIM

---

### 📚 **Book Hub** — Digital Library Management System
*Full-stack MERN application for book discovery and reservations*

**Repository:** [Book-hub-](https://github.com/rohithsaravanas-star/Book-hub-)

Comprehensive digital library platform with:
- Real-time dynamic book search with multiple filters
- Atomic transaction-based reservation system
- Role-based access control (Member/Admin)
- JWT authentication with bcrypt password hashing
- Optimized MongoDB schema with text indexes
- Responsive React SPA with state management

**Tech:** React 18, Node.js, Express.js, MongoDB, Mongoose, JWT, Axios, RESTful API

### 🕳️ **Sewer Sentinel** — Edge AI IoT Monitoring System
*Real-time hazardous gas detection with LoRa telemetry*

**Repository:** [Sewer-Sentinal-](https://github.com/rohithsaravanas-star/Sewer-Sentinal-)

IoT safety platform for confined space monitoring:
- Multi-threshold hazardous gas detection (MQ-5 sensor)
- Real-time environmental tracking (DHT22)
- Automatic & manual ventilation control via relay
- Long-range LoRa 433MHz wireless telemetry
- Edge AI integration ready for anomaly detection
- Interactive serial CLI for testing and debugging

**Tech:** ESP32, C++, PlatformIO, Edge Impulse, LoRa SX1278, OLED, Sensor Integration
