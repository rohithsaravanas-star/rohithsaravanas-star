## About

I work on three overlapping areas: full-stack web applications, autonomous AI systems with large language models, and IoT platforms with embedded machine learning. Right now I'm most interested in multi-agent AI orchestration, real-time data processing, and making intelligent systems that actually work in production.

My projects tend to bridge frontend and backend—I'll build a React interface one day and optimize a FastAPI pipeline the next. I've spent time with TypeScript, Python, and C++, depending on what the problem needs. Clean code and performance matter to me more than shipping fast.

## What I'm Working On

**ForgeMind X**  
A multi-agent AI system for manufacturing engineering. Six specialized agents (requirements, design, simulation, manufacturing, cost, reporting) orchestrated with NVIDIA NIM and Llama 3.1. Generates 3D models, runs FEA simulations, and creates PDF reports automatically.  
[Repository](https://github.com/rohithsaravanas-star/ForgeMind-X) — TypeScript, FastAPI, Python, Three.js, MongoDB

**Sewer Sentinel**  
Real-time monitoring for confined spaces. Detects hazardous gases on an ESP32, streams data over LoRa for extended range coverage. Built with sensor integration and edge AI in mind.  
[Repository](https://github.com/rohithsaravanas-star/Sewer-Sentinal-) — C++, PlatformIO, Edge Impulse, LoRa

**Book Hub**  
A full-stack library management system. Real-time search, reservation system with MongoDB transactions, and role-based access. Built to understand transaction patterns and optimized queries.  
[Repository](https://github.com/rohithsaravanas-star/Book-hub-) — React, Express.js, MongoDB, JWT

**Portfolio**  
Interactive portfolio site deployed on Vercel.  
[Repository](https://github.com/rohithsaravanas-star/Portfolio-) — React, Vite
